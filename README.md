# Master's thesis at Unipd: the code

This code implements the Markov-chains based algorithms derived in my MSc thesis in Mathematical Epidemiology at the University of Padova: "A stochastic SIS epidemic model with recovery times having a generalized Erlang distribution".

My MSc thesis is now public on the University of Padova website : https://thesis.unipd.it/handle/20.500.12608/108126 .

This code employs the Python libraries: NumPy and matplotlib.pyplot.
